# 实验实现（未实车验收）

本目录是在原始工程基础上完成的课程任务扩展，**不是已验证的标准答案**。

## C10B 课程实现（`c10b-course/`）

相对原始工程增加：

- 16×16 汉字字库与 OLED 汉字距离显示；
- PA8/TIM1_CH1 舵机 PWM；
- 5 扇区超声扫描与 500/550 mm 滞回避障；
- TIM7 独立 100 Hz 时基，扫描/上报不再依赖 MPU INT；
- 23 字节上报帧（包含 Pitch/Roll/Yaw、距离、舵机扇区、扫描掩码）。

## C50C 中期实现（`c50c-midterm/`）

相对原始工程增加：

- 23 字节协议解析与 OLED 第 1/2/4 页；
- 3 m 往返状态机：OUT / PAUSE / TURN / BACK / DONE；
- 航向/横向保持；
- 陀螺仪辅助 180° 掉头，IMU 失效时回退轮速航向；
- 总路程/平均速度显示。
