# 课程完成检查清单

打印或复制到实验记录中使用。每一项都应有现象/数据，不要只打勾。

## A. 环境与硬件

- [ ] Keil MDK 5.41 安装完成
- [ ] ARM Compiler 5 可用
- [ ] STM32F1xx / STM32F4xx Pack 安装
- [ ] ST-LINK 驱动正常，设备管理器可见
- [ ] CH9102 / USB-TTL 驱动正常，COM 口可见
- [ ] C10B、C50C 都能 Rebuild，0 Error
- [ ] C10B 烧录后能运行
- [ ] C50C 烧录后能运行
- [ ] 舵机 5 V、GND、PA8 接线正确
- [ ] 超声 5 V、PC15、PA1、GND 接线正确
- [ ] C10B PC12 → C50C PA3、共地

## B. 实验一：OLED 汉字距离

- [ ] 16×16 字模已生成
- [ ] “距离”和“米”显示正常
- [ ] 数字/小数点显示清晰
- [ ] 纸箱从 30 cm 移到 5 cm，读数连续变化
- [ ] 移开纸箱，读数恢复
- [ ] 记录一张 OLED 照片

## C. 实验二：舵机 + 单超声

- [ ] 舵机左右扫动
- [ ] `S` 在 -60/-30/0/30/60 变化
- [ ] 斜前方 30°、40 cm 物体能触发 STOP
- [ ] 移开物体后恢复 GO
- [ ] 能解释单超声盲区与扫描局限

## D. 实验三：串口与姿态

- [ ] USB-TTL 接 USART1，115200-8-N-1
- [ ] 串口助手能看到调试数据
- [ ] C10B 姿态随倾斜/旋转变化
- [ ] C50C 第 2 页显示 PITCH/ROLL/YAW
- [ ] 两端协议版本一致（12 或 23 字节）
- [ ] C50C 接收计数 RX/HEAD/OK/BAD 合理

## E. 中期检查

- [ ] 起点标线清晰，前方 ≥3.5 m
- [ ] 上电后前 10 s 保持静止
- [ ] 前进约 3.00 m
- [ ] 50 cm 内障碍停车
- [ ] 障碍撤离后继续
- [ ] 终点原地掉头约 180°
- [ ] 返回起点
- [ ] OLED 显示总路程/均速
- [ ] 记录实测距离、横向偏差、返回误差

## F. 提交

- [ ] 源码在个人分支，不覆盖 original
- [ ] 无 OBJ/hex/uvguix 等构建产物
- [ ] 测试记录/照片/日志齐全
- [ ] 更新对应 docs 页面
- [ ] 提交 PR 或打标签
