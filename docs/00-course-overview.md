# 课程总览

## 1. 课程定位

本课程以 WHEELTEC C10B/C50C 双板麦克纳姆轮小车为载体，串联：

- 嵌入式工具链与下载；
- OLED 显示与字模；
- 超声测距与舵机扫描；
- MPU6050 姿态与串口通信；
- 编码器里程计、运动学与闭环控制；
- 中期综合任务：3 m 直线、避障暂停、原地掉头、返回。

## 2. 学习路径（按实际课次）

| 课次 | 内容 | 主要产出 |
|---|---|---|
| 1 | PPT 第一讲：显示与执行 | OLED/超声/舵机基础 |
| 2–3 | 小车组装 | 机械/电气装配 |
| 4 | PPT 第二讲：姿态感知 | MPU6050/DMP 姿态 |
| 5 | 电机控制实训 | 速度/距离控制、五道运动题 |
| 6 | PPT 第三讲：串口通讯 | 13/12 字节报文、调试 |
| 7 | 综合实验 | 汉字距离、单超声扫描、姿态上报 |
| 中期 | 3 m 往返 | 避障、掉头、返回、统计 |

完整页码与原文对照见 [课程进度与资料对照](00-lesson-map.md)。

往届学生的课程体验、团队配置和硬件坑见 [往届经验与总结](13-student-experience.md)。该页是主观参考，不是官方要求。

## 3. 原始资料与工程

本仓库遵循“原始优先”：

1. 先读原始课件与原始工程；
2. 按 `docs/` 步骤做实验；
3. 需要参考实现时，再看 `firmware/experimental/`；
4. 实验代码未通过实车验收前，不作为标准答案。

原始资料位置：

- 传感器讲义/PPT：`docs/reference/sensors/`
- 机械/电气/安装手册：`docs/reference/hardware/`
- 烧录/ST-LINK 教程：`docs/reference/toolchain/`
- 舵机参考源码：`references/servo-example/`

特别注意：

- PPT 第一讲 p22–25 讲“汉字要自己取模/尝试中文”，但没有逐字写“16×16”；
- “16×16 + 距离0.05米”来自第七次课课程布置；
- 中期 3 m/50 cm/掉头/返回/平均速度来自课程布置，不在原 PDF 固定章节中。

## 5. 推荐实验记录

每次实验至少记录：

- 日期、板卡、Target、烧录方式；
- 关键接线照片/表；
- OLED/串口现象；
- 测量数据（距离、时间、路径偏差）；
- 失败现象与排查结论；
- 是否通过验收。

## 6. 课程验收原则

- 代码存在不等于功能完成；
- 编译通过不等于硬件可用；
- “已验证”必须有实车记录；
- 原始工程能恢复现场，实验工程用于对照与改进。
