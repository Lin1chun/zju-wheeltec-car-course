# 串口协议

## 1. 物理层

| 项目 | 值 |
|---|---|
| C10B 发送 | UART5：PC12 TX / PD2 RX |
| C50C 接收 | USART2：PA2 TX / PA3 RX |
| 波特率 | 115200 |
| 格式 | 8 数据位、1 停止位、无校验、无流控 |
| 连接 | TX/RX 交叉，共地 |

## 2. K210 → C10B：13 字节帧（PPT p154–155）

| 字节 | 字段 | 说明 |
|---|---|---|
| 0 | `0xCC` | 帧头 |
| 1~4 | `Cam_W/Cam_H` | 图像宽高，小端 |
| 5~6 | `cx` | 目标中心 X |
| 7~8 | `cy` | 目标中心 Y |
| 9~10 | `size` | 目标面积 |
| 11 | BCC | 0~10 字节异或 |
| 12 | `0xDD` | 帧尾 |

## 3. 原始 C10B → C50C：12 字节帧（PPT p156）

`#pragma pack(1)`，小端：

| 字节 | 字段 | 说明 |
|---|---|---|
| 0~1 | `0xCC 0xDD` | 双字节帧头 |
| 2 | `k210_alive` | K210 在线 |
| 3~4 | `k210_cx` | 目标中心 X |
| 5~6 | `k210_size` | 目标面积 |
| 7~8 | `distance` | 超声距离，mm |
| 9~10 | `temperature` | 温度 ×100 |
| 11 | `BCCcheck` | 前 11 字节异或 |

原始帧**不包含姿态**。

## 4. C50C → 上位机：24 字节遥测帧（电机手册 p86–88）

| 字节 | 字段 |
|---|---|
| 0 | `0x7B` 帧头 |
| 1 | 软件失能标志 |
| 2~7 | Vx/Vy/Vz（各 2 字节） |
| 8~13 | 加速度 X/Y/Z |
| 14~19 | 角速度 X/Y/Z |
| 20~21 | 电池电压 |
| 22 | BCC（0~21 异或） |
| 23 | `0x7D` 帧尾 |

## 5. C50C 运动控制输入：11 字节帧（原始 `uartx_callback.c`）

| 字节 | 字段 |
|---|---|
| 0 | `0x7B` |
| 1 | 控制类型（0 普通/1、2 回充/3 对接） |
| 2 | 参数 |
| 3~4 | Vx，mm/s |
| 5~6 | Vy，mm/s |
| 7~8 | Vz，mm/s |
| 9 | BCC（`Check_BCC(buffer,9)`，即 buffer[0..8]） |
| 10 | `0x7D` |

> 原工程代码为 `Check_BCC(buffer,9)`，即对 buffer[0..8] 异或；代码附近注释写“2~8”不准确，以实际函数调用为准。

## 6. 实验 23 字节帧（课程扩展）

| 字节 | 字段 | 单位/说明 |
|---|---|---|
| 0~1 | `0xCC 0xDD` | 帧头 |

| 3 | `flags` | bit0 障碍，bit1 中心超声有效，bit2 K210 |

## 7. BCC

发送端：

```c
bcc = 0;
for (i = 0; i < len - 1; i++) bcc ^= data[i];
data[len - 1] = bcc;
```

接收端对前 `len-1` 字节重新计算并比较。

## 8. 兼容性规则

1. 两端必须同一协议版本；
2. 修改字段顺序/长度时，同时更新两端结构体；
3. 保持 `#pragma pack(1)`；
4. 更新本文档与 `AGENTS.md` 检查清单；
5. 接收端保留 RX/HEAD/OK/BAD 计数，便于现场判断。

## 9. 常见错配

| 现象 | 可能原因 |
|---|---|
| 完全无数据 | 接线、共地、波特率、端口 |
| 有字节但 HEAD=0 | 端口/波特率/噪声 |
| HEAD>0、OK=0、BAD>0 | 12/23 字节错配或字段/BCC 不一致 |
| OK>0 但数值异常 | 字段映射、单位、符号 |
