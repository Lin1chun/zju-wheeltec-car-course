# 实验一：16×16 汉字显示小车距离

## 1. 实验目标

在 OLED 上使用 16×16 点阵汉字显示超声距离，例如：

```text
距离 0.05米
```

验收要点：

- 汉字为 16×16 点阵；
- 数字/小数点清晰；
- 移动纸箱，距离连续变化；
- C10B 或 C50C 至少一块屏可稳定显示。

## 2. 原始基线

原始 C10B 工程只提供 ASCII 字库，OLED 上显示 `dis 0.00` 一类字符，不含汉字。原始资料：

- 传感器讲义 OLED/字模章节；
- `references/` 中的原始工程；
- `docs/reference/sensors/传感器与串口通讯-完整版.pdf`。

## 3. 原理

SSD1306 的 GRAM 按页组织，每页 8 行。一个 16×16 汉字占：

- 16 列；
- 2 页；
- 共 32 字节。

推荐字模格式：

```text
page0: col0..col15  （上半 8 行）
page1: col0..col15  （下半 8 行）
```

每个字节的 bit0 对应页内最上面一行。

## 4. 实现步骤

1. 取模：用宋体/点阵工具生成 16×16 汉字；
2. 新建 `oledfont_cn16.h`，保存所需字模（距离米路程均速）；
3. 在 OLED 驱动中增加 `OLED_ShowCN16(x,y,glyph)`；
4. 绘制时同时写 1/0，避免旧字残影；
5. 在显示任务中拼接：
   - 汉字“距离”；
   - 固定两位小数距离；
   - 汉字“米”；
6. 距离来自 C10B 的超声测量值 `ranger_dis`。

## 5. 测试

1. 小车/前板上电；
2. 纸箱放在超声前方约 30 cm；
3. 缓慢移动到约 5 cm；
4. OLED 数字应连续变化；
5. 移开纸箱，距离应回到较大值/量程值。

## 6. 常见问题

| 现象 | 排查 |
|---|---|
| 一直 0.00 | 超声供电、Trig/Echo、PA1 捕获、MPU/时基 |
| 汉字乱码 | 字模/编码/字节顺序错误 |
| 汉字有残影 | 未清除背景像素 |
| 数字越界 | 整数位宽不足或值异常 |
| C10B 有、C50C 无 | 两板串口/协议/接线 |
