# 实验三：USB 转串口与姿态上报

## 1. 实验目标

1. 使用 USB 转串口和串口调试助手查看 C10B 调试数据；
2. 把 C10B 计算的 Pitch/Roll/Yaw 发送到 C50C；
3. 在 C50C OLED 上显示姿态。

## 2. 串口连接

USB-TTL 接 C10B USART1：

```text
USB-TTL RX  → C10B PA9  (USART1_TX)
USB-TTL TX  → C10B PA10 (USART1_RX)
USB-TTL GND → C10B GND
```

串口助手设置：

```text
波特率 115200
数据位 8
停止位 1
校验 None
流控 None
```

## 3. 原始 C10B 输出

原始 C10B 工程通过 `printf` 重定向到 USART1，可用于观察姿态、温度、距离等调试信息。具体输出以原始工程为准。

课件依据：

- PPT 第二讲 p112：实验三“从裸数据到角度”；
- p113：角度一直为 0 时优先怀疑 DMP 固件；
- PPT 第三讲 p154–155：K210→C10B 13 字节帧；
- p156：C10B→C50C 12 字节帧；
- p163：实验四“三块板联调”；
- p165 课后任务原文：“把C10B计算的姿态数据发给C50C，并在OLED上显示。”

## 4. 原始协议与实验协议

### 原始 12 字节帧

原始 C10B → C50C 帧只包含 K210 状态/坐标/面积、距离、温度，**不包含姿态**。

### 实验 23 字节帧

课程扩展帧增加：

- 前方/扫描最小距离；
- Pitch / Roll / Yaw（×100）；
- 舵机扇区；
- 扫描有效掩码；
- 障碍标志。

两端必须是同一版本。C50C 若仍使用原始 12 字节结构体，会表现为“有字节但校验失败/收不到”。

> 12 字节是 PPT p156 的原始协议；23 字节是课程实验扩展，不是课件原文。

完整字段见 [串口协议](../protocol.md)。

## 5. C50C 显示

实验工程 OLED：

- 第 1 页：距离/路程/均速/状态；
- 第 2 页：C10B ATTITUDE（PITCH/ROLL/YAW）；
- 第 4 页：C10B LINK（RX/HEAD/OK/BAD 计数）。

用户键循环翻页。

## 6. 测试

1. 连接 USB-TTL，打开串口助手；
2. C10B 上电，确认每秒有调试输出；
3. 转动/倾斜 C10B，P/R/Y 应变化；
4. 按 C50C 用户键到第 2 页，姿态应与 C10B 一致；
5. 第 4 页：
   - RX 约 460/s；
   - HEAD/OK 约 20/s；
   - BAD 应接近 0。

## 7. 故障判断

| 第 4 页现象 | 结论 |
|---|---|
| RX=0 | C50C PA3 没收到信号：接线、共地、插错座 |
| RX>0，HEAD=0 | 波特率/端口/干扰；字节不是 `CC DD` 帧 |
| HEAD>0，OK=0，BAD>0 | 帧长/校验不匹配：12/23 字节协议不一致 |
| OK>0，距离=0 | 字段映射或 C10B 距离本身为 0 |
| C10B 调试正常，C50C 无数据 | 先查两板协议版本，再查 UART5→USART2 接线 |

## 8. 状态

课程工程已通过实车验收，C50C 第 2 页可显示 Pitch、Roll、Yaw。

### 重要代码坑：C50C 的 USART2 初始化

原始 C50C `USER/system.c` 中：

```c
/*
USART2_Init(115200);
*/
```

这行默认被注释。USART2 的 GPIO、时钟、NVIC 和 RXNE 中断都不会初始化，`USART2_IRQHandler` 写得再对也不会触发，表现为：

- C50C 第 4 页 `RX=0`；
- C50C 收不到 C10B 的距离/姿态；
- 页 2 `NOLNK` 一直存在。

课程工程已调用 `USART2_Init(115200);`。修改该初始化后必须重新 Rebuild 并检查第 4 页计数。

## 9. 第二讲与实验四要点

### 第二讲（PPT p57–114）

- 先读 WHO_AM_I 和原始加速度/陀螺数据；
- 静止时看陀螺零偏，偏大先校准；
- DMP 输出四元数，再换算 Pitch/Roll/Yaw；
- Yaw 会漂移，只能做相对转角或外加磁力计；
- 角度一直 0 时优先查 DMP 固件/加载返回值（PPT p113）。

### 实验四联调顺序（PPT p163）

1. 单板自环：TX 接 RX，发什么收什么；
2. 接串口助手：115200 能打印一行字；
3. 接 K210：看 cx/cy/size 是否变化；
4. 接 C50C：底盘收到 20 Hz 报文并能动。

### 中断时间预算

PPT p111 估算 12 字节 @20 Hz 约占 1.04 ms/10 ms。实验 23 字节帧约为两倍，因此实验实现把扫描/上报移到 TIM7 独立时基，避免继续挤占 MPU 中断；这不改变“PPT 原始协议是 12 字节”的事实。
