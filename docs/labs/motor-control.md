# 第五次课：电机控制实训

## 1. 课程定位

本页对应原始 `小车电机控制实验手册.pdf`，是 C50C 底板电机控制的基础实验，不是第七次课的传感器综合任务。

## 2. 原始手册结构

| 小节 | PDF 页 | 内容 |
|---|---:|---|
| 三、实验信息/原理/内容 | p24 | 通过 Vx/Vy/Vz 与停止距离控制小车 |
| `Start_Move_Dist()` | p77 | 设置速度、目标距离 |
| 实验现象与数据 | p90 | OLED 目标/实际轮速、停车现象 |
| 实验思考题 | p92 | 五道运动题 |

## 3. 基础实验

原始示例在 `balance_task.c` 的 `Start_Move_Dist()` 中设置：

```c
robot_control.Vx = 0.1f;
robot_control.Vy = 0.0f;
robot_control.Vz = 0.0f;
robot_distance.target_dist = 2.0f;
```

现象：

- 自检后前进；
- OLED 四轮目标/实际速度约 100 mm/s；
- 到达约 2 m 后停车；
- 四轮目标/实际回到 0。

## 4. 五道思考题（PDF p92 原文）

1. 编程实现小车倒退 2 米。
2. 编程实现小车向左移动 1 米。
3. 编程实现小车斜 45°移动 1 米。
4. 编程实现小车逆时针转动 90°。
5. 编程实现小车沿 L 型轨迹移动。

## 5. 需要理解的代码

- `Start_Move_Dist()`：速度与目标距离；
- `Drive_Motor()`：运动学逆解 + 速度平滑；
- `Mecanum_Distance_Control()`：里程计距离与停车；
- `Get_Robot_FeedBack()`：编码器反馈与单轮位移；
- `ResponseControl()`：四轮 PI 控制；
- OLED：目标/实际轮速显示。

## 6. 实验步骤

1. 打开原始 C50C 工程，Target `Mec_Car`；
2. 编译、下载、复位；
3. 留出 2 m 以上空间；
4. 观察自检与前进；
5. 修改 `Start_Move_Dist()`，逐题验证；
6. 记录实际距离/方向/时间，不要只看代码。

## 7. 与第七次课的关系

第五次课训练“能设定速度/距离让车动起来”；第七次课再把 C10B 的超声、舵机、姿态串进来。

中期 3 m 往返是后续课程布置，不是本手册 p92 的思考题；本手册只列五道运动题。
