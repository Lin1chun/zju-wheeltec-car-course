# 第七次课：三项综合任务

本页把第七次课的三项任务与前面课件、实验对应起来。

## 1. 任务 1：16×16 汉字显示距离

课件基础：

- 第一讲 p22：汉字要自己取模，PCtoLCD2002，阴码、逐列式、顺向；
- 第一讲 p25：实验一“点亮第一行字”，尝试中文；
- 第一讲 p26–40：HC-SR04 测距。

课程布置：

- 16×16 点阵；
- 示例“距离0.05米”。

实现文档：[OLED 汉字距离](oled-distance.md)。

验收：

- 汉字/数字清晰；
- 纸箱 30 cm→5 cm，读数连续变化。

## 2. 任务 2：单超声波扩大避障范围

课件原文（第一讲 p56）：

> 只使用一个超声波的情况下如何实现更大范围的避障？

课件基础：

- 超声 p26–40；
- 舵机 p45–55；
- 实验二 p53–55。

实现文档：[舵机与单超声扫描](servo-ultrasonic.md)。

建议答案：舵机带动超声分扇区扫描，前方 ±45° 作为危险区；单传感器仍看不到车后，扫描周期存在盲区。

验收：

- 舵机扫动；
- 斜前方 30° 纸箱可被发现；
- 移开后恢复。

## 3. 任务 3：姿态数据发 C50C 并显示

课件原文（第三讲 p165）：

> 把C10B计算的姿态数据发给C50C，并在OLED上显示。

课件基础：

- 第二讲 p57–114：MPU6050/DMP/Pitch/Roll/Yaw；
- 第三讲 p154–156：K210 13 字节、C10B→C50C 12 字节；
- p163：三块板联调。

实现文档：[姿态与串口](serial-attitude.md)、[串口协议](../protocol.md)。

验收：

- USB-TTL 串口助手能看调试数据；
- C50C 第 2 页显示 P/R/Y；
- 姿态变化时数据变化；
- 两端协议版本一致。

## 4. 三项任务的系统关系

```text
HC-SR04 ─┐
舵机 ────┼→ C10B ──UART5──→ C50C ──→ 电机/底盘
MPU6050 ─┘       │
                 └→ OLED：距离/姿态
```

C10B 负责“感知与显示”，C50C 负责“底盘与综合显示”。
