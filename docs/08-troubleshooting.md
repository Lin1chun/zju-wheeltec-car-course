# 故障排查

## 1. 烧录

| 现象 | 处理 |
|---|---|
| Keil 找不到 ST-LINK | 设备管理器看 `STM32 STLink`；装 ST-LINK 驱动；换线/口 |
| `Flash Download failed - Cortex-M3` | 装 F1 DFP；选 High-density Flash；Erase Full Chip |
| `Programming Done` 但内容不匹配 | 算法错误/写保护/旧固件未擦除；整片擦除或换下载器 |
| 只有 Build 没有 LOAD | Build 不写芯片；必须 LOAD |
| LOAD 后行为没变 | 复位/重新上电；确认烧的是当前 Target |

## 2. 串口

| 现象 | 处理 |
|---|---|
| 端口列表没有 COM | 先在设备管理器确认；装 CH9102/CH340 驱动；换数据线 |
| 串口助手无数据 | RX/TX 交叉、GND、波特率、是否选对 COM |
| 发送有、接收无 | 检查目标板是否使用该串口、是否只发不收 |
| 数据乱码 | 波特率/时钟/校验 |

## 3. 超声/OLED

| 现象 | 处理 |
|---|---|
| 距离一直 0.00 | 5V 供电、Trig PC15、Echo PA1、TIM2 捕获、100 Hz 时基 |
| 手动靠近无变化 | 换超声模块；确认模块 5V；检查回波线 |
| 汉字乱码 | 字模格式、编码、页/列顺序 |
| 汉字残影 | 绘制时清除背景像素 |

## 4. C50C 收不到 C10B

优先看 C50C 第 4 页 `C10B LINK`：

| 现象 | 结论 |
|---|---|
| RX=0 | PA3 无信号：接线、共地、插错座 |
| RX>0，HEAD=0 | 波特率/端口/噪声 |
| HEAD>0，OK=0，BAD>0 | 协议版本/长度/BCC 不一致 |
| OK>0，距离=0 | 字段/显示/源数据 |

同时确认：

```text
C10B PC12 → C50C PA3
C10B PD2  ← C50C PA2
GND ↔ GND
```

## 5. 姿态恒为 0

- 看 C10B OLED 温度是否变化：
  - 温度也 0：MPU6050 I2C/INT 未工作；
  - 温度变化但 P/R/Y=0：DMP/FIFO 读取失败；
- 检查 PB14/PB15 I2C、PB9 INT、3.3V/GND；
- 确认芯片为 MPU6050，不是 ICM20948；
- 检查 `MPU6050_initialize()`、`DMP_Init()`、`Read_DMP()` 返回值/执行情况。

## 6. 舵机

| 现象 | 处理 |
|---|---|
| 完全不动 | PA8、5V、GND、TIM1 CH1 |
| 抖动/复位 | 独立 5V 供电，共地 |
| 只往一边转 | 脉宽范围/舵机限位 |
| `S` 不变化 | 100 Hz 扫描时基未运行 |

## 7. 车型/运动

- OLED `TYPE:` 与硬件不符：检查电位器、Target、`Robot_Init()` 参数；
- 麦轮距离偏大/偏小：轮径/减速比/编码器参数；
- 车轮反转：先修接线/轮向，再考虑代码符号；
- 通信中断车不停：检查链路看门狗。
