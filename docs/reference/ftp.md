## 5. 当前网络排查记录

2026-11-03 从当前开发环境测试：

- 主机 `10.13.12.198` 可 ping；
- TCP `3301` 可建立连接；
- FTP 控制连接没有返回 banner，HTTP/FTPS 试连也无响应；
- 判断：可能受校园网/VPN/代理限制，或服务器仅允许特定网段。

请优先在**校园网、关闭 VPN/代理**的环境下用 FileZilla 重试。

常见问题：

| 现象 | 处理 |
|---|---|
| 连接后一直空白 | 断开 VPN/代理，换校园网；试 FileZilla |
| 530 登录失败 | 核对用户名/密码；确认不是匿名登录 |
| 425/426 数据连接失败 | 切换 Passive/Active；检查防火墙 |
| 能登录但列不出目录 | 被动模式端口被挡；换网络或让老师开端口 |
| 资料与本地不一致 | 以 FTP 为准，重新下载后更新本地镜像 |
