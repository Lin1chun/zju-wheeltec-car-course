# 串口协议

## 1. 物理层

| 项目 | 值 |
|---|---|
| C10B 发送 | UART5：PC12 TX / PD2 RX |
| C50C 接收 | USART2：PA2 TX / PA3 RX |
| 波特率 | 115200 |
| 格式 | 8 数据位、1 停止位、无校验、无流控 |
| 连接 | TX/RX 交叉，共地 |

## 2. 原始 12 字节帧

`#pragma pack(1)`，小端：

| 字节 | 字段 | 说明 |
|---|---|---|
| 0~1 | `0xCC 0xDD` | 双字节帧头 |
| 2 | `k210_alive` | K210 在线 |
| 3~4 | `k210_cx` | 目标中心 X |
| 5~6 | `k210_size` | 目标面积 |
| 7~8 | `distance` | 超声距离，mm |
| 9~10 | `temperature` | 温度 ×100 |
| 11 | `BCCcheck` | 前 11 字节异或 |

原始帧**不包含姿态**。

## 3. 实验 23 字节帧

| 字节 | 字段 | 单位/说明 |
|---|---|---|
| 0~1 | `0xCC 0xDD` | 帧头 |
| 2 | `k210_alive` | K210 在线 |
| 3 | `flags` | bit0 障碍，bit1 中心超声有效，bit2 K210 |
| 4~5 | `k210_cx` | 目标中心 X |
| 6~7 | `k210_size` | 目标面积 |
| 8~9 | `distance` | 前方扇区最小距离，mm |
| 10~11 | `distance_min` | 整圈扫描最小距离，mm |
| 12~13 | `temperature` | ×100 ℃ |
| 14~15 | `pitch` | ×100° |
| 16~17 | `roll` | ×100° |
| 18~19 | `yaw` | ×100° |
| 20 | `servo_deg` | 当前扇区 -60/-30/0/30/60 |
| 21 | `scan_mask` | bit0~4 对应五扇区有效 |
| 22 | `BCCcheck` | 前 22 字节异或 |

## 4. BCC

发送端：

```c
bcc = 0;
for (i = 0; i < len - 1; i++) bcc ^= data[i];
data[len - 1] = bcc;
```

接收端对前 `len-1` 字节重新计算并比较。

## 5. 兼容性规则

1. 两端必须同一协议版本；
2. 修改字段顺序/长度时，同时更新两端结构体；
3. 保持 `#pragma pack(1)`；
4. 更新本文档与 `AGENTS.md` 检查清单；
5. 接收端保留 RX/HEAD/OK/BAD 计数，便于现场判断。

## 6. 常见错配

| 现象 | 可能原因 |
|---|---|
| 完全无数据 | 接线、共地、波特率、端口 |
| 有字节但 HEAD=0 | 端口/波特率/噪声 |
| HEAD>0、OK=0、BAD>0 | 12/23 字节错配或字段/BCC 不一致 |
| OK>0 但数值异常 | 字段映射、单位、符号 |
