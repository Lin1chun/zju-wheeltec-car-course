# 中期检查：3 m 直线往返与避障

## 1. 验收要求

> 要求来源说明：3 m、50 cm、原地掉头、返回起点、总路程/平均速度来自课程中期检查布置，
> **不在提供的传感器/电机 PDF 固定章节中**。电机手册 p92 只列五道运动思考题，不等于中期要求。

1. 沿直线前进 3 m，不能明显走偏；
2. 前方 50 cm 内检测到障碍物时停车，不能碰撞；
3. 障碍物撤离后继续；
4. 到 3 m 终点原地掉头；
5. 返回起点；
6. OLED 显示总路程和平均车速。

## 2. 原始基线

原始 C50C 的 `Start_Move_Dist()` 只提供简单的距离前进示例（例如前进 2 m 后停车），不包含：

- 障碍暂停/恢复；
- 180° 原地掉头；
- 返回起点；
- 总路程/平均速度统计。

因此中期任务需要在原始工程上扩展。

## 3. 实验实现思路

`course/2026-midterm` 分支的 `firmware/experimental/c50c-midterm/` 状态机：

```text
WAIT → OUT → (PAUSE) → TURN → BACK → DONE
```

| 状态 | 行为 |
|---|---|
| WAIT | 等待 C10B 有效帧/前方扇区数据 |
| OUT | 以 0.12 m/s 前进，航向/横向保持 |
| PAUSE | 前方 <500 mm 停车，撤离并稳定 0.4 s 后恢复 |
| TURN | 原地 180°，陀螺仪测真实角度，IMU 失效回退轮速 |
| BACK | 掉头后前进 3 m 返回起点 |
| DONE | 停车，锁存总路程/平均速度 |

## 4. 关键参数

| 参数 | 默认 | 说明 |
|---|---:|---|
| `MID_SPEED` | 0.12 m/s | 巡航速度 |
| `MID_TARGET_DIST` | 3.00 m | 单程 |
| `MID_DIST_TOL` | 0.02 m | 停车容差 |
| `MID_STOP_MM` | 500 mm | 障碍阈值 |
| `MID_CLEAR_MM` | 550 mm | 恢复阈值 |
| `MID_CLEAR_TICKS` | 40（0.4 s） | 撤离确认 |
| `MID_TURN_TOL_DEG` | 1° | 掉头容差 |
| `MID_TURN_MAX` | 0.6 rad/s | 转向限速 |

## 5. 控制策略

- 前进：编码器里程计积分 `dx`；
- 直线：编码器航向 `yaw` + 横向偏移 `dy` 闭环；
- 掉头：C50C ICM20948 陀螺仪积分；300 ms 后与轮速航向比对，自动判断轴向；IMU 无响应回退轮速；
- 返回：掉头后车头朝起点，继续前进；
- 通信中断：0.5 s 看门狗停车。

## 6. 测试步骤

1. 地面标出起点线，前方至少 3.5 m；
2. 车头对准起点，保持前 10 s 静止（陀螺仪零偏校准）；
3. 上电，等待 WAIT→OUT；
4. 在 1–2 m 处放纸箱，确认停车；
5. 撤离纸箱，确认 0.4 s 后继续；
6. 到 3 m 处观察原地掉头；
7. 回程再次测试障碍暂停；
8. 停车后记录：
   - 起点到终点实测距离；
   - 横向偏差；
   - 掉头角度；
   - 返回点误差；
   - OLED 总路程/均速。

## 7. 验收判定建议

| 项目 | 建议标准 |
|---|---|
| 单程距离 | 3.00 m ± 3 cm |
| 直线偏差 | 在课程要求内，记录实测 |
| 障碍 | 50 cm 前停车，无接触 |
| 恢复 | 撤离后稳定 0.4 s 再走 |
| 掉头 | 180° ± 2°（以实测记录为准） |
| 返回 | 返回起点附近，记录误差 |
| 显示 | 总路程≈6 m，均速合理 |

## 8. 状态与风险

该实现**尚未完成实车验收**，且依赖 C10B→C50C 通信与 MPU 姿态。当前已知：

- 两板通信未闭环；
- MPU P/R/Y 恒为 0；
- 掉头/直线误差未实测。

在上述问题解决前，不应把本实现作为标准答案。
