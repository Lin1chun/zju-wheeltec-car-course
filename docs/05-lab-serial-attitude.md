# 实验三：USB 转串口与姿态上报

## 1. 实验目标

1. 使用 USB 转串口和串口调试助手查看 C10B 调试数据；
2. 把 C10B 计算的 Pitch/Roll/Yaw 发送到 C50C；
3. 在 C50C OLED 上显示姿态。

## 2. 串口连接

USB-TTL 接 C10B USART1：

```text
USB-TTL RX  → C10B PA9  (USART1_TX)
USB-TTL TX  → C10B PA10 (USART1_RX)
USB-TTL GND → C10B GND
```

串口助手设置：

```text
波特率 115200
数据位 8
停止位 1
校验 None
流控 None
```

## 3. 原始 C10B 输出

原始 C10B 工程通过 `printf` 重定向到 USART1，可用于观察姿态、温度、距离等调试信息。具体输出以原始工程为准。

## 4. 原始协议与实验协议

### 原始 12 字节帧

原始 C10B → C50C 帧只包含 K210 状态/坐标/面积、距离、温度，**不包含姿态**。

### 实验 23 字节帧

课程扩展帧增加：

- 前方/扫描最小距离；
- Pitch / Roll / Yaw（×100）；
- 舵机扇区；
- 扫描有效掩码；
- 障碍标志。

两端必须是同一版本。C50C 若仍使用原始 12 字节结构体，会表现为“有字节但校验失败/收不到”。

完整字段见 [串口协议](07-serial-protocol.md)。

## 5. C50C 显示

实验工程 OLED：

- 第 1 页：距离/路程/均速/状态；
- 第 2 页：C10B ATTITUDE（PITCH/ROLL/YAW）；
- 第 4 页：C10B LINK（RX/HEAD/OK/BAD 计数）。

用户键循环翻页。

## 6. 测试

1. 连接 USB-TTL，打开串口助手；
2. C10B 上电，确认每秒有调试输出；
3. 转动/倾斜 C10B，P/R/Y 应变化；
4. 按 C50C 用户键到第 2 页，姿态应与 C10B 一致；
5. 第 4 页：
   - RX 约 460/s；
   - HEAD/OK 约 20/s；
   - BAD 应接近 0。

## 7. 故障判断

| 第 4 页现象 | 结论 |
|---|---|
| RX=0 | C50C PA3 没收到信号：接线、共地、插错座 |
| RX>0，HEAD=0 | 波特率/端口/干扰；字节不是 `CC DD` 帧 |
| HEAD>0，OK=0，BAD>0 | 帧长/校验不匹配：12/23 字节协议不一致 |
| OK>0，距离=0 | 字段映射或 C10B 距离本身为 0 |
| C10B 调试正常，C50C 无数据 | 先查两板协议版本，再查 UART5→USART2 接线 |
